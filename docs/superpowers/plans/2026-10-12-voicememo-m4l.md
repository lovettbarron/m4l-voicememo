# VoiceMemo Max for Live Device Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Max for Live Audio Effect that lists the user's iCloud-synced Apple Voice Memos, analyses a selected memo (segments, loudness, tempo, pitch/key, speech vs music), and pulls a chosen window into a Session clip slot.

**Architecture:** All logic lives in plain CommonJS Node modules under `src/` (unit-tested with `node --test`). A thin `node.script` entry (`src/max/vm-core.js`) wires them to Max through `src/core/controller.js`, a dependency-injected state machine that is fully testable without Max. Live Object Model work runs in a Max `[js]` script (`src/max/lom-bridge.js`), UI in three `[jsui]` scripts, and the `.amxd` is generated by `tools/build-device.py` so the patch is reproducible from source.

**Tech Stack:** Node for Max (Node 22.18 in Live 12.4), `node:sqlite` with `/usr/bin/sqlite3` fallback, `/usr/bin/afconvert` + `/usr/bin/afinfo`, Max `[js]`/`[jsui]` (ES5), Python 3 (build script only), `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-12-voicememo-m4l-design.md`

## Global Constraints

- Minimum **Live 12.0.5** (`ClipSlot.create_audio_clip`), **macOS 13 Ventura**. Primary test target Live 12.4.x on macOS 27.
- Node code must run on **Node 22.18** (the version bundled with Max 9.1.5). Do not use APIs newer than Node 22.18, even though the dev machine runs Node 26.
- **No runtime npm dependencies.** Only Node built-ins, `max-api` (provided by Node for Max), and macOS system binaries in `/usr/bin`.
- `[js]` and `[jsui]` scripts are **ES5** (no `let`/`const`/arrow functions/template literals) so they run in Max 8.6 (Live 12.0.x) as well as Max 9.
- The Voice Memos library is **never written to**. The DB is opened read-only, or a temp copy is read.
- Library paths: macOS 14+ `~/Library/Group Containers/group.com.apple.VoiceMemos.shared/Recordings`; macOS 13 `~/Library/Application Support/com.apple.voicememos/Recordings`.
- Cache dir: `~/Music/Ableton/User Library/VoiceMemo Cache/`. Pulled clips: `<Set folder>/Samples/Imported/VoiceMemo/<title>-<mmss>-<mmss>.wav`, or `<cache>/Pulled/` when the Set path is unknown.
- Device UI: height 169 px, width 760 px, every action clickable and the main ones exposed as Live parameters.
- Full-res audio is never loaded whole into memory or `buffer~`. Analysis uses the mono 11025 Hz analysis WAV; Pull reads only the window's byte range; audition streams with `sfplay~`.
- Tempo/key/class are labelled as estimates (`≈`) in the UI.

## Review Focus

1. **Memo titles with slashes, colons, emoji or >60 chars**: Pull must write a valid filename that still looks like the title (Task 12 test `sanitize keeps readable unicode and strips path separators`).
2. **Hour-long memos**: segmentation and peaks on long audio must stay fast enough not to stall the UI (Task 3 test `segments handles 10 minutes of audio quickly`).
3. **All-silent or empty memos**: no segments must fall back to the whole memo, and a <50 ms window must disable Pull rather than write a file (Task 7 tests `seg preset without segments covers whole memo`, `isPullable rejects windows shorter than 50 ms`).
4. **Set tempo or time signature changes after a window is chosen**: bar presets must recompute (Task 13 test `tempo change recomputes bar windows`).
5. **Memo file disappears or conversion fails after listing** (evicted to iCloud, deleted on iPhone): must show an error state, not crash or hang (Task 13 test `conversion failure reports error state`).

```js
'use strict';
const TAU = 2 * Math.PI;

function sine(freq, seconds, sr = 11025, amp = 0.5) {
  const n = Math.round(seconds * sr);
  const a = new Float32Array(n);
  for (let i = 0; i < n; i++) a[i] = amp * Math.sin((TAU * freq * i) / sr);
  return a;
}

function harmonic(freq, seconds, sr = 11025, amp = 0.5) {
  const n = Math.round(seconds * sr);
  const a = new Float32Array(n);
  for (let i = 0; i < n; i++) {
    const t = (TAU * freq * i) / sr;
    a[i] = amp * (0.6 * Math.sin(t) + 0.3 * Math.sin(2 * t) + 0.1 * Math.sin(3 * t));
  }
  return a;
}

function silence(seconds, sr = 11025) {
  return new Float32Array(Math.round(seconds * sr));
}

function noise(seconds, sr = 11025, amp = 0.5, seed = 1) {
  const n = Math.round(seconds * sr);
  const a = new Float32Array(n);
  let s = seed >>> 0;
  for (let i = 0; i < n; i++) {
    s = (Math.imul(s, 1103515245) + 12345) >>> 0;
    a[i] = amp * ((s / 0xffffffff) * 2 - 1);
  }
  return a;
}

function clicks(bpm, seconds, sr = 11025) {
  const a = silence(seconds, sr);
  const step = (sr * 60) / bpm;
  for (let pos = 0; pos < a.length; pos += step) {
    const i0 = Math.round(pos);
    for (let k = 0; k < 200 && i0 + k < a.length; k++) {
      a[i0 + k] = 0.9 * Math.exp(-k / 30) * Math.sin((TAU * 1000 * k) / sr);
    }
  }
  return a;
}

function concat(...arrays) {
  const out = new Float32Array(arrays.reduce((n, a) => n + a.length, 0));
  let o = 0;
  for (const a of arrays) { out.set(a, o); o += a.length; }
  return out;
}

function midiToHz(m) { return 440 * Math.pow(2, (m - 69) / 12); }

function melody(midiNotes, noteSeconds, sr = 11025) {
  return concat(...midiNotes.map((m) => harmonic(midiToHz(m), noteSeconds, sr)));
}

// Alternating unvoiced noise bursts, pitch-gliding voiced bursts and short gaps.
function speechLike(seconds, sr = 11025) {
  const parts = [];
  let total = 0;
  let k = 0;
  while (total < seconds) {
    parts.push(noise(0.12, sr, 0.3, 7 + k));
    const n = Math.round(0.15 * sr);
    const glide = new Float32Array(n);
    let phase = 0;
    const f0 = k % 2 ? 110 : 140;
    for (let i = 0; i < n; i++) {
      const f = f0 + (150 * i) / n;
      phase += (TAU * f) / sr;
      glide[i] = 0.4 * Math.sin(phase);
    }
    parts.push(glide, silence(0.08, sr));
    total += 0.35;
    k++;
  }
  return concat(...parts);
}

module.exports = { sine, harmonic, silence, noise, clicks, concat, melody, midiToHz, speechLike };
```

```js
'use strict';
const fs = require('fs');

const FORMAT_PCM = 1;
const FORMAT_FLOAT = 3;
const FORMAT_EXTENSIBLE = 0xfffe;

function parseHeader(fd) {
  const head = Buffer.alloc(12);
  fs.readSync(fd, head, 0, 12, 0);
  if (head.toString('ascii', 0, 4) !== 'RIFF' || head.toString('ascii', 8, 12) !== 'WAVE') {
    throw new Error('not a RIFF/WAVE file');
  }
  const chunk = Buffer.alloc(8);
  let pos = 12;
  let fmt = null;
  while (fs.readSync(fd, chunk, 0, 8, pos) === 8) {
    const id = chunk.toString('ascii', 0, 4);
    const size = chunk.readUInt32LE(4);
    if (id === 'fmt ') {
      const b = Buffer.alloc(size);
      fs.readSync(fd, b, 0, size, pos + 8);
      let format = b.readUInt16LE(0);
      if (format === FORMAT_EXTENSIBLE && size >= 26) format = b.readUInt16LE(24);
      fmt = { format, channels: b.readUInt16LE(2), sampleRate: b.readUInt32LE(4), bitsPerSample: b.readUInt16LE(14) };
    } else if (id === 'data') {
      if (!fmt) throw new Error('WAV data chunk before fmt chunk');
      return { ...fmt, dataOffset: pos + 8, dataSize: size };
    }
    pos += 8 + size + (size & 1);
  }
  throw new Error('WAV has no data chunk');
}

function sampleReader(format, bits) {
  if (format === FORMAT_FLOAT && bits === 32) return (b, o) => b.readFloatLE(o);
  if (format !== FORMAT_PCM) throw new Error(`unsupported WAV format ${format}`);
  if (bits === 16) return (b, o) => b.readInt16LE(o) / 32768;
  if (bits === 24) return (b, o) => b.readIntLE(o, 3) / 8388608;
  if (bits === 32) return (b, o) => b.readInt32LE(o) / 2147483648;
  throw new Error(`unsupported bit depth ${bits}`);
}

function decode(buf, h, frames) {
  const bytes = h.bitsPerSample / 8;
  const read = sampleReader(h.format, h.bitsPerSample);
  const out = Array.from({ length: h.channels }, () => new Float32Array(frames));
  let o = 0;
  for (let i = 0; i < frames; i++) {
    for (let c = 0; c < h.channels; c++, o += bytes) out[c][i] = read(buf, o);
  }
  return out;
}

function readRange(path, startS, endS) {
  const fd = fs.openSync(path, 'r');
  try {
    const h = parseHeader(fd);
    const frameBytes = (h.channels * h.bitsPerSample) / 8;
    const total = Math.floor(h.dataSize / frameBytes);
    const s = Math.max(0, Math.min(total, Math.floor(startS * h.sampleRate)));
    const e = endS === Infinity ? total : Math.max(s, Math.min(total, Math.round(endS * h.sampleRate)));
    const frames = e - s;
    const buf = Buffer.alloc(frames * frameBytes);
    if (frames > 0) fs.readSync(fd, buf, 0, buf.length, h.dataOffset + s * frameBytes);
    return { sampleRate: h.sampleRate, channels: decode(buf, h, frames) };
  } finally {
    fs.closeSync(fd);
  }
}

function read(path) {
  return readRange(path, 0, Infinity);
}

function write(path, audio, { bitDepth = 24 } = {}) {
  if (bitDepth !== 16 && bitDepth !== 24) throw new Error(`unsupported bit depth ${bitDepth}`);
  const { sampleRate, channels } = audio;
  const nch = channels.length;
  const frames = nch ? channels[0].length : 0;
  const bytes = bitDepth / 8;
  const dataSize = frames * nch * bytes;
  const buf = Buffer.alloc(44 + dataSize);
  buf.write('RIFF', 0, 'ascii');
  buf.writeUInt32LE(36 + dataSize, 4);
  buf.write('WAVE', 8, 'ascii');
  buf.write('fmt ', 12, 'ascii');
  buf.writeUInt32LE(16, 16);
  buf.writeUInt16LE(FORMAT_PCM, 20);
  buf.writeUInt16LE(nch, 22);
  buf.writeUInt32LE(sampleRate, 24);
  buf.writeUInt32LE(sampleRate * nch * bytes, 28);
  buf.writeUInt16LE(nch * bytes, 32);
  buf.writeUInt16LE(bitDepth, 34);
  buf.write('data', 36, 'ascii');
  buf.writeUInt32LE(dataSize, 40);
  const max = bitDepth === 16 ? 32767 : 8388607;
  let o = 44;
  for (let i = 0; i < frames; i++) {
    for (let c = 0; c < nch; c++, o += bytes) {
      const v = Math.round(Math.max(-1, Math.min(1, channels[c][i])) * max);
      if (bitDepth === 16) buf.writeInt16LE(v, o);
      else buf.writeIntLE(v, o, 3);
    }
  }
  fs.writeFileSync(path, buf);
}

function processAudio(audio, { fadeMs = 5, normalize = false, targetDb = -1 } = {}) {
  const channels = audio.channels.map((ch) => Float32Array.from(ch));
  const n = channels.length ? channels[0].length : 0;
  const fade = Math.min(Math.floor(n / 2), Math.round((audio.sampleRate * fadeMs) / 1000));
  let gain = 1;
  if (normalize) {
    let peak = 0;
    for (const ch of channels) for (let i = 0; i < n; i++) peak = Math.max(peak, Math.abs(ch[i]));
    if (peak > 0) gain = Math.pow(10, targetDb / 20) / peak;
  }
  for (const ch of channels) {
    if (gain !== 1) for (let i = 0; i < n; i++) ch[i] *= gain;
    for (let i = 0; i < fade; i++) {
      const g = i / fade;
      ch[i] *= g;
      ch[n - 1 - i] *= g;
    }
  }
  return { sampleRate: audio.sampleRate, channels };
}

module.exports = { read, readRange, write, process: processAudio, parseHeader };
```

```js
function sampleRange(length, sr, [start, end]) {
  const s = Math.max(0, Math.min(length, Math.floor(start * sr)));
  const e = Math.max(s, Math.min(length, Math.floor(end * sr)));
```

```js
'use strict';

function peaks(mono, bins) {
  const out = new Float32Array(Math.max(0, bins) * 2);
  const n = mono.length;
  if (!n) return out;
  for (let b = 0; b < bins; b++) {
    const s = Math.floor((b * n) / bins);
    const e = Math.max(s + 1, Math.floor(((b + 1) * n) / bins));
    let lo = Infinity;
    let hi = -Infinity;
    for (let i = s; i < e && i < n; i++) {
      const v = mono[i];
      if (v < lo) lo = v;
      if (v > hi) hi = v;
    }
    out[2 * b] = lo === Infinity ? 0 : lo;
    out[2 * b + 1] = hi === -Infinity ? 0 : hi;
  }
  return out;
}
```

```js
'use strict';

const round3 = (x) => Math.round(x * 1000) / 1000;

function segments(mono, sr, opts = {}) {
  const { thresholdDb = -40, minSilenceMs = 300, minSegmentMs = 250, padMs = 30 } = opts;
  const hop = Math.max(1, Math.round(sr * 0.01));
  const nFrames = Math.floor(mono.length / hop);
  const thr = Math.pow(10, thresholdDb / 20);
  const thrSq = thr * thr;
  const runs = [];
  let runStart = -1;
  for (let f = 0; f < nFrames; f++) {
    const base = f * hop;
    let sum = 0;
    for (let i = 0; i < hop; i++) {
      const v = mono[base + i];
      sum += v * v;
    }
    const active = sum / hop > thrSq;
    if (active && runStart < 0) runStart = f;
    if (!active && runStart >= 0) {
      runs.push([runStart, f]);
      runStart = -1;
    }
  }
  if (runStart >= 0) runs.push([runStart, nFrames]);

  const frameMs = (hop / sr) * 1000;
  const merged = [];
  for (const r of runs) {
    const last = merged[merged.length - 1];
    if (last && (r[0] - last[1]) * frameMs < minSilenceMs) last[1] = r[1];
    else merged.push([r[0], r[1]]);
  }

  const duration = mono.length / sr;
  const pad = padMs / 1000;
  const frameS = hop / sr;
  return merged
    .filter(([a, b]) => (b - a) * frameMs >= minSegmentMs)
    .map(([a, b]) => ({
      start: round3(Math.max(0, a * frameS - pad)),
      end: round3(Math.min(duration, b * frameS + pad)),
    }));
}

module.exports = { segments };
```

```js
'use strict';
const { sampleRange } = require('./range');

const NAMES = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'];
// Krumhansl-Kessler key profiles, index 0 = tonic.
const MAJOR = [6.35, 2.23, 3.48, 2.33, 4.38, 4.09, 2.52, 5.19, 2.39, 3.66, 2.29, 2.88];
const MINOR = [6.33, 2.68, 3.52, 5.38, 2.6, 3.53, 2.54, 4.75, 3.98, 2.69, 3.34, 3.17];
const FRAME = 2048;
const HOP = 512;
const GATE = 0.01; // about -40 dBFS RMS

function yinFrame(x, sr, { minF = 70, maxF = 1000, threshold = 0.15 } = {}) {
  const maxLag = Math.min(Math.floor(sr / minF), Math.floor(x.length / 2));
  const minLag = Math.max(2, Math.floor(sr / maxF));
  const w = x.length - maxLag;
  const cmnd = new Float32Array(maxLag + 1);
  cmnd[0] = 1;
  let running = 0;
  for (let tau = 1; tau <= maxLag; tau++) {
    let d = 0;
    for (let i = 0; i < w; i++) {
      const v = x[i] - x[i + tau];
      d += v * v;
    }
    running += d;
    cmnd[tau] = running > 0 ? (d * tau) / running : 1;
  }
  let tau = -1;
  for (let t = minLag; t <= maxLag; t++) {
    if (cmnd[t] < threshold) {
      while (t + 1 <= maxLag && cmnd[t + 1] < cmnd[t]) t++;
      tau = t;
      break;
    }
  }
  if (tau < 0) return { f0: null, clarity: 0 };
  let refined = tau;
  if (tau > 1 && tau < maxLag) {
    const a = cmnd[tau - 1];
    const b = cmnd[tau];
    const c = cmnd[tau + 1];
    const den = a - 2 * b + c;
    if (den !== 0) refined = tau + (0.5 * (a - c)) / den;
  }
  return { f0: sr / refined, clarity: 1 - cmnd[tau] };
}

function pearson(a, b) {
  const n = a.length;
  const ma = a.reduce((s, v) => s + v, 0) / n;
  const mb = b.reduce((s, v) => s + v, 0) / n;
  let num = 0;
  let da = 0;
  let db = 0;
  for (let i = 0; i < n; i++) {
    num += (a[i] - ma) * (b[i] - mb);
    da += (a[i] - ma) ** 2;
    db += (b[i] - mb) ** 2;
  }
  return da && db ? num / Math.sqrt(da * db) : 0;
}

function estimateKey(hist) {
  let best = { key: null, corr: -Infinity };
  for (let tonic = 0; tonic < 12; tonic++) {
    for (const [mode, profile] of [['major', MAJOR], ['minor', MINOR]]) {
      const rotated = hist.map((_, pc) => profile[(pc - tonic + 12) % 12]);
      const corr = pearson(hist, rotated);
      if (corr > best.corr) best = { key: `${NAMES[tonic]} ${mode}`, corr };
    }
  }
  return best;
}

function framePositions(s, e, maxFrames) {
  const count = Math.max(0, Math.floor((e - s - FRAME) / HOP) + 1);
  const step = Math.max(1, Math.ceil(count / maxFrames));
  const out = [];
  for (let k = 0; k < count; k += step) out.push(s + k * HOP);
  return out;
}

function pitch(mono, sr, win, { maxFrames = 400 } = {}) {
  const [s, e] = sampleRange(mono.length, sr, win);
  const positions = framePositions(s, e, maxFrames);
  const hist = new Array(12).fill(0);
  const midis = [];
  for (const p of positions) {
    const x = mono.subarray(p, p + FRAME);
    let sum = 0;
    for (let i = 0; i < x.length; i++) sum += x[i] * x[i];
    if (Math.sqrt(sum / x.length) < GATE) continue;
    const { f0, clarity } = yinFrame(x, sr);
    if (!f0) continue;
    const midi = 69 + 12 * Math.log2(f0 / 440);
    midis.push(midi);
    hist[((Math.round(midi) % 12) + 12) % 12] += clarity;
  }
  if (midis.length < 3) return { note: null, key: null, confidence: 0 };
  midis.sort((a, b) => a - b);
  const median = Math.round(midis[Math.floor(midis.length / 2)]);
  const note = `${NAMES[((median % 12) + 12) % 12]}${Math.floor(median / 12) - 1}`;
  const { key, corr } = estimateKey(hist);
  const voicedRatio = midis.length / positions.length;
  return { note, key, confidence: Math.max(0, Math.min(1, voicedRatio * Math.max(0, corr))) };
}

module.exports = { yinFrame, pitch };
```

```js
'use strict';
const { sampleRange } = require('./range');

function onsetEnvelope(mono, s, e, hop) {
  const win = hop * 2;
  const n = Math.max(0, Math.floor((e - s - win) / hop));
  const env = new Float32Array(n);
  let prev = null;
  for (let k = 0; k < n; k++) {
    const base = s + k * hop;
    let sum = 0;
    for (let i = 0; i < win; i++) {
      const v = mono[base + i];
      sum += v * v;
    }
    const le = Math.log(1e-10 + sum / win);
    env[k] = prev === null ? 0 : Math.max(0, le - prev);
    prev = le;
  }
  let mean = 0;
  for (let k = 0; k < n; k++) mean += env[k];
  mean /= n || 1;
  for (let k = 0; k < n; k++) env[k] -= mean;
  return env;
}

function tempo(mono, sr, win, { minBpm = 60, maxBpm = 180, minConfidence = 0.2 } = {}) {
  const [s, e] = sampleRange(mono.length, sr, win);
  if ((e - s) / sr < 4) return { bpm: null, confidence: 0 };
  const hop = Math.max(1, Math.round(sr / 86));
  const fr = sr / hop;
  const env = onsetEnvelope(mono, s, e, hop);
  const n = env.length;
  const acf = (lag) => {
    let sum = 0;
    for (let k = 0; k + lag < n; k++) sum += env[k] * env[k + lag];
    return sum;
  };
  const r0 = acf(0);
  if (!(r0 > 1e-9)) return { bpm: null, confidence: 0 };
  const minLag = Math.max(2, Math.floor((60 * fr) / maxBpm));
  const maxLag = Math.ceil((60 * fr) / minBpm);
  const vals = new Map();
  for (let lag = minLag - 1; lag <= maxLag + 1; lag++) vals.set(lag, acf(lag));
  let best = minLag;
  for (let lag = minLag; lag <= maxLag; lag++) if (vals.get(lag) > vals.get(best)) best = lag;
  const a = vals.get(best - 1);
  const b = vals.get(best);
  const c = vals.get(best + 1);
  const den = a - 2 * b + c;
  const lag = den !== 0 ? best + (0.5 * (a - c)) / den : best;
  const confidence = Math.max(0, Math.min(1, b / r0));
  if (confidence < minConfidence) return { bpm: null, confidence };
  return { bpm: Math.round(((60 * fr) / lag) * 10) / 10, confidence };
}

module.exports = { tempo };
```

```js
'use strict';
const { sampleRange } = require('./range');
const { yinFrame } = require('./pitch');

const FRAME = 1024;
const HOP = 512;
const MAX_FRAMES = 600; // ~28 s of contiguous frames at 11025 Hz
const GATE = Math.pow(10, -45 / 20);

function classify(mono, sr, win) {
  const [s, e] = sampleRange(mono.length, sr, win);
  const total = Math.max(0, Math.floor((e - s - FRAME) / HOP) + 1);
  const count = Math.min(total, MAX_FRAMES);
  const s0 = s + Math.floor((total - count) / 2) * HOP; // centre block for long windows
  let active = 0;
  let voiced = 0;
  let stable = 0;
  let pairs = 0;
  let prevMidi = null;
  const zcrs = [];
  for (let k = 0; k < count; k++) {
    const x = mono.subarray(s0 + k * HOP, s0 + k * HOP + FRAME);
    let sum = 0;
    let zc = 0;
    for (let i = 0; i < x.length; i++) {
      sum += x[i] * x[i];
      if (i && (x[i] >= 0) !== (x[i - 1] >= 0)) zc++;
    }
    if (Math.sqrt(sum / x.length) < GATE) {
      prevMidi = null;
      continue;
    }
    active++;
    zcrs.push(zc / x.length);
    const { f0 } = yinFrame(x, sr);
    if (!f0) {
      prevMidi = null;
      continue;
    }
    voiced++;
    const midi = 69 + 12 * Math.log2(f0 / 440);
    if (prevMidi !== null) {
      pairs++;
      if (Math.abs(midi - prevMidi) < 0.5) stable++;
    }
    prevMidi = midi;
  }
  if (active < 5) return { label: 'unknown', confidence: 0 };
  const voicedRatio = voiced / active;
  const stability = pairs ? stable / pairs : 0;
  const mean = zcrs.reduce((a, b) => a + b, 0) / zcrs.length;
  const sd = Math.sqrt(zcrs.reduce((a, b) => a + (b - mean) ** 2, 0) / zcrs.length);
  const zcrCv = mean > 0 ? sd / mean : 0;
  const score = 0.4 * voicedRatio + 0.4 * stability + 0.2 * (1 - Math.min(1, zcrCv));
  const label = score >= 0.6 ? 'music' : score <= 0.4 ? 'speech' : 'unknown';
  return { label, confidence: Math.min(1, Math.abs(score - 0.5) * 2) };
}

module.exports = { classify };
```

```js
'use strict';

const PRESETS = ['seg', '1bar', '2bar', '4bar', '8bar', '5s', '10s', '30s'];
const MIN_LENGTH = 0.05;
const SNAP_RANGE = 1;

function presetLength(preset, tempo = 120, beatsPerBar = 4) {
  const m = /^(\d+)(bar|s)$/.exec(preset);
  if (!m) return null;
  const n = Number(m[1]);
  return m[2] === 's' ? n : (n * beatsPerBar * 60) / tempo;
}

function nearestSegmentStart(t, segments) {
  let best = null;
  for (const s of segments) {
    const d = Math.abs(s.start - t);
    if (d <= SNAP_RANGE && (best === null || d < Math.abs(best - t))) best = s.start;
  }
  return best;
}

function resolve({ preset, anchorS = null, segmentIndex = 0, segments = [], tempo = 120, beatsPerBar = 4, snap = true, duration }) {
  if (!(duration > 0)) return null;
  const idx = Math.max(0, Math.min(segments.length - 1, segmentIndex));
  if (preset === 'seg') {
    if (!segments.length) return { start: 0, end: duration };
    return { start: segments[idx].start, end: Math.min(duration, segments[idx].end) };
  }
  const len = presetLength(preset, tempo, beatsPerBar);
  if (len === null) throw new Error(`unknown preset ${preset}`);
  let start = anchorS !== null ? anchorS : segments.length ? segments[idx].start : 0;
  if (snap && segments.length) {
    const snapped = nearestSegmentStart(start, segments);
    if (snapped !== null) start = snapped;
  }
  start = Math.max(0, Math.min(duration, start));
  return { start, end: Math.min(duration, start + len) };
}

function fromDrag({ start, end }, duration) {
  return {
    start: Math.max(0, Math.min(duration, Math.min(start, end))),
    end: Math.max(0, Math.min(duration, Math.max(start, end))),
  };
}

function isPullable(w) {
  return !!w && w.end - w.start >= MIN_LENGTH - 1e-9;
}

function bars(seconds, tempo, beatsPerBar = 4) {
  return (seconds * tempo) / 60 / beatsPerBar;
}

function segmentAt(t, segments) {
  return segments.findIndex((s) => t >= s.start && t <= s.end);
}

module.exports = { PRESETS, MIN_LENGTH, presetLength, resolve, fromDrag, isPullable, bars, segmentAt };
```

```js
'use strict';
const fs = require('fs');
const os = require('os');
const path = require('path');

const LIBRARY_DIRS = [
  'Library/Group Containers/group.com.apple.VoiceMemos.shared/Recordings',
  'Library/Application Support/com.apple.voicememos/Recordings',
];

function tryRead(dir, fsImpl) {
  try {
    fsImpl.readdirSync(dir);
    return 'ok';
  } catch (e) {
    if (e.code === 'EPERM' || e.code === 'EACCES') return 'denied';
    return 'missing';
  }
}

function locate({ home = os.homedir(), overridePath = null, fsImpl = fs } = {}) {
  if (overridePath) {
    return tryRead(overridePath, fsImpl) === 'ok'
      ? { mode: 'folder', root: overridePath }
      : { mode: 'none', reason: 'folder-unreadable' };
  }
  let denied = null;
  for (const rel of LIBRARY_DIRS) {
    const root = path.join(home, rel);
    const r = tryRead(root, fsImpl);
    if (r === 'denied') {
      denied = denied || root;
      continue;
    }
    if (r === 'missing') continue;
    const dbPath = path.join(root, 'CloudRecordings.db');
    return fsImpl.existsSync(dbPath) ? { mode: 'library', root, dbPath } : { mode: 'folder', root };
  }
  return denied ? { mode: 'none', reason: 'no-fda', root: denied } : { mode: 'none', reason: 'not-found' };
}

module.exports = { locate, LIBRARY_DIRS };
```

```js
  };

  const rows = queryWithRetry(location.dbPath, `SELECT ${select.join(', ')} FROM ZCLOUDRECORDING`, adapter);
  return rows.map((r) => toMemo(r, location.root));
}

    const out = execFileSync('/usr/bin/afinfo', [file], { encoding: 'utf8' });
    const m = /estimated duration:\s*([\d.]+)/.exec(out);
    return m ? Number(m[1]) : null;
  } catch {
    return null;
  }
}

        title: path.basename(f, path.extname(f)),

        duration: durationOf(abs),

        status: 'local',

      };
```

```js
'use strict';
const fs = require('fs');
const path = require('path');
const { execFile, spawn } = require('child_process');
const { safeId } = require('../util/ids');

function probe(src) {
  return new Promise((resolve, reject) => {
    execFile('/usr/bin/afinfo', [src], { encoding: 'utf8' }, (err, out) => {
      if (err) return reject(new Error(`afinfo failed: ${String(err.message).split('\n')[0]}`));
      const ch = /(\d+)\s+ch,/.exec(out);
      const dur = /estimated duration:\s*([\d.]+)/.exec(out);
      resolve({ channels: ch ? Number(ch[1]) : 2, duration: dur ? Number(dur[1]) : null });
    });
  });
}

function isFresh(dst, src) {
  try {
    return fs.statSync(dst).mtimeMs >= fs.statSync(src).mtimeMs;
  } catch {
    return false;
  }
}

function afconvert(args, src, dst, expectedBytes, onProgress) {
  const tmp = `${dst}.part.wav`;
  return new Promise((resolve, reject) => {
    const proc = spawn('/usr/bin/afconvert', [...args, src, tmp]);
    let stderr = '';
    proc.stderr.on('data', (d) => { stderr += d; });
    const timer = setInterval(() => {
      try {
        onProgress(Math.min(0.99, fs.statSync(tmp).size / expectedBytes));
      } catch {
        // tmp not created yet
      }
    }, 200);
    const fail = (msg) => {
      clearInterval(timer);
      fs.rmSync(tmp, { force: true });
      reject(new Error(msg));
    };
    proc.on('error', (e) => fail(`afconvert failed: ${e.message}`));
    proc.on('close', (code) => {
      if (code !== 0) return fail(`afconvert failed (${code}): ${stderr.trim().split('\n')[0] || 'unknown error'}`);
      clearInterval(timer);
      fs.renameSync(tmp, dst);
      onProgress(1);
      resolve(dst);
    });
  });
}

async function convert(memo, cacheDir, { onProgress = () => {}, onAnalysisReady = () => {} } = {}) {
  if (!memo.path || !fs.existsSync(memo.path)) {
    throw Object.assign(new Error('Recording not downloaded'), { code: 'ENOENT' });
  }
  fs.mkdirSync(cacheDir, { recursive: true });
  const base = path.join(cacheDir, safeId(memo.id));
  const analysisWav = `${base}.a.wav`;
  const fullWav = `${base}.wav`;
  const info = await probe(memo.path);
  const duration = info.duration || memo.duration || 60;

  if (!isFresh(analysisWav, memo.path)) {
    await afconvert(['-f', 'WAVE', '-d', 'LEI16@11025', '-c', '1', '--mix'], memo.path, analysisWav,
      duration * 11025 * 2, (f) => onProgress('analysis', f));
  }
  onAnalysisReady(analysisWav);

  if (!isFresh(fullWav, memo.path)) {
    const channels = Math.min(2, info.channels);
    const mix = info.channels > 2 ? ['-c', '2', '--mix'] : [];
    await afconvert(['-f', 'WAVE', '-d', 'LEI24@44100', ...mix], memo.path, fullWav,
      duration * 44100 * 3 * channels, (f) => onProgress('full', f));
  }
  return { fullWav, analysisWav };
}

module.exports = { convert, probe };
```

```js
'use strict';
const fs = require('fs');
const path = require('path');
const wav = require('./audio/wav');

function sanitize(name) {
  const cleaned = String(name || '')
    .replace(/[/\\:*?"<>|\u0000-\u001f]/g, '_')
    .replace(/\s+/g, ' ')
    .trim();
  const clipped = Array.from(cleaned).slice(0, 60).join('').trim();
  return clipped || 'memo';
}

function mmss(seconds) {
  const t = Math.max(0, Math.floor(seconds));
  return String(Math.floor(t / 60)).padStart(2, '0') + String(t % 60).padStart(2, '0');
}

function pullDir({ setPath, cacheDir }) {
  return setPath
    ? path.join(path.dirname(setPath), 'Samples', 'Imported', 'VoiceMemo')
    : path.join(cacheDir, 'Pulled');
}

function uniquePath(dir, base) {
  let p = path.join(dir, `${base}.wav`);
  for (let n = 2; fs.existsSync(p); n++) p = path.join(dir, `${base}-${n}.wav`);
  return p;
}

function writePull({ fullWav, title, start, end, normalize = false, setPath = null, cacheDir, fadeMs = 5 }) {
  const dir = pullDir({ setPath, cacheDir });
  fs.mkdirSync(dir, { recursive: true });
  const audio = wav.process(wav.readRange(fullWav, start, end), { fadeMs, normalize, targetDb: -1 });
  const out = uniquePath(dir, `${sanitize(title)}-${mmss(start)}-${mmss(end)}`);
  wav.write(out, audio, { bitDepth: 24 });
  return out;
}

module.exports = { sanitize, mmss, pullDir, writePull };
```

```js
const PEAK_BINS = 600;

function createController({ deps, send, cacheDir, home }) {
  const st = {
    overridePath: null,
    memos: [],
    memo: null,
    files: null,

      send('state', { name: loc.reason === 'no-fda' ? 'no-access' : 'empty', reason: loc.reason });
      return;

      st.memos = deps.catalog.list(loc);

    send('memos', { items: st.memos });
    if (!st.memos.length) send('state', { name: 'empty', reason: 'no-memos' });

      st.pendingRestore = null;
      if (st.memos.some((m) => m.id === id)) {
        send('select', id);
        setImmediate(() => selectMemo(id));
      }
    }
  }

    st.overridePath = p || null;
    refresh();
  }

    if (!id || (st.memo && st.memo.id === id)) return;
    if (st.memos.length && st.memos.some((m) => m.id === id)) {
      send('select', id);
      selectMemo(id);
    } else st.pendingRestore = id;

    const a = deps.readWav(analysisWav);
    st.mono = a.channels[0];
    st.sr = a.sampleRate;
    st.duration = st.mono.length / st.sr;
    send('waveform', { peaks: Array.from(deps.peaks(st.mono, PEAK_BINS)), duration: st.duration });

    const memo = st.memos.find((m) => m.id === id);
    if (!memo) return;
    const token = ++st.token;
    const current = () => token === st.token;
    Object.assign(st, { memo, files: null, mono: null, segments: [], windows: {}, window: null, anchorS: null, manual: null });
    st.params.segment = 0;
    send('header', { title: memo.title, date: memo.date, duration: memo.duration });
    if (memo.status !== 'local') {
      send('state', { name: 'notice', message: 'Not downloaded. Open it once in Voice Memos.' });
      send('pullenable', 0);
      return;
    }
    send('state', { name: 'loading' });
    let files;
    try {
      files = await deps.convert(memo, cacheDir, {
        onProgress: (phase, fraction) => current() && send('progress', { phase, fraction }),
        onAnalysisReady: (p) => current() && showWaveform(p),
      });
      if (!current()) return;
      if (!st.mono) showWaveform(files.analysisWav);
    } catch (e) {
      if (current()) send('state', { name: 'error', message: e.message });
      return;
    }
    st.files = files;
    send('audio', files.fullWav);
    loadSegments();
    send('segmentindex', 0);
    recompute();
    send('state', { name: 'ready' });
    if (st.params.auto) audition();

  function loadSegments() {
    const cached = deps.cache.get(st.memo.id, mtimeOf(st.memo.path));
    if (cached && cached.settingsKey === settingsKey()) {
      st.segments = cached.segments;
      st.windows = cached.windows || {};
    } else {
      st.segments = deps.segments(st.mono, st.sr, {
        thresholdDb: st.settings.thresholdDb,
        minSilenceMs: st.settings.minSilenceMs,
      });
      st.windows = {};
      persist();
    }
    send('segments', { items: st.segments });
  }

  function persist() {
    if (!st.memo) return;
    try {
      deps.cache.put(st.memo.id, mtimeOf(st.memo.path), { settingsKey: settingsKey(), segments: st.segments, windows: st.windows });
    } catch {
      // cache is best-effort
    }
  }

  function analysisFor(w) {
    const key = `${w.start.toFixed(3)}-${w.end.toFixed(3)}`;
    if (!st.windows[key]) {
      const range = [w.start, w.end];
      const safe = (fn) => {
        try {
          return fn(st.mono, st.sr, range);
        } catch {
          return null;
        }
      };
      st.windows[key] = { loudness: safe(deps.loudness), tempo: safe(deps.tempo), pitch: safe(deps.pitch), classify: safe(deps.classify) };
      persist();
    }
    return st.windows[key];
  }

    if (!st.mono) return;
    const preset = W.PRESETS[st.params.length] || 'seg';
    st.window = st.manual || W.resolve({
      preset,
      anchorS: st.anchorS,
      segmentIndex: st.params.segment,
      segments: st.segments,
      tempo: st.tempo,
      beatsPerBar: st.beatsPerBar,

    const length = st.window.end - st.window.start;
    send('window', { start: st.window.start, end: st.window.end });
    send('windowinfo', {
      start: st.window.start,
      end: st.window.end,
      length,
      bars: W.bars(length, st.tempo, st.beatsPerBar),
      segment: st.params.segment,
      segmentCount: st.segments.length,
      analysis: analysisFor(st.window),
    });
    send('pullenable', W.isPullable(st.window) ? 1 : 0);
  }

  function setParam(name, value) {
    const v = Number(value);
    if (name in st.params) {
      st.params[name] = v;
      if (name === 'segment') {
        st.anchorS = null;
        st.manual = null;
      }
      if (name === 'length') st.manual = null;
      if (name !== 'auto' && name !== 'norm') recompute();
      return;
    }
    if (name in st.settings) {
      st.settings[name] = v;
      if (name !== 'fadeMs' && st.mono) {
        st.segments = deps.segments(st.mono, st.sr, { thresholdDb: st.settings.thresholdDb, minSilenceMs: st.settings.minSilenceMs });
        persist();
        send('segments', { items: st.segments });
        recompute();
      }
    }
  }

  function anchor(seconds) {
    const t = Number(seconds);
    st.manual = null;
    if ((W.PRESETS[st.params.length] || 'seg') === 'seg') {
      const i = W.segmentAt(t, st.segments);
      if (i < 0) return;
      st.params.segment = i;
      send('segmentindex', i);
    } else st.anchorS = t;
    recompute();
  }

  function drag(start, end) {
    if (!st.mono) return;
    st.manual = W.fromDrag({ start: Number(start), end: Number(end) }, st.duration);
    recompute();
  }

  function audition() {
    if (!st.window || !st.files) return;
    send('audition', Math.round(st.window.start * 1000), Math.round(st.window.end * 1000));
  }

  function pull() {
    if (!st.files || !W.isPullable(st.window)) {
      send('status', { level: 'error', message: 'Nothing to pull' });
      return;
    }
    if (!st.target.ok) {
      send('status', { level: 'error', message: st.target.label });
      return;
    }
    try {
      const out = deps.writePull({
        fullWav: st.files.fullWav,
        title: st.memo.title,
        start: st.window.start,
        end: st.window.end,
        normalize: !!st.params.norm,
        setPath: st.setPath,
        cacheDir,
        fadeMs: st.settings.fadeMs,
      });
      send('pull', out);
    } catch (e) {
      send('status', { level: 'error', message: `Pull failed: ${e.message}` });
    }
  }

  function pullResult(ok, message) {
    send('status', { level: Number(ok) ? 'ok' : 'error', message: String(message) });
  }

  function setTempo(bpm, beatsPerBar) {
    st.tempo = Number(bpm) > 0 ? Number(bpm) : 120;
    st.beatsPerBar = Number(beatsPerBar) > 0 ? Number(beatsPerBar) : 4;
    recompute();
  }

  function setSetPath(p) {
    st.setPath = p ? String(p) : null;
  }

  function setTarget(ok, label) {
    st.target = { ok: !!Number(ok), label: String(label) };
    send('target', st.target);
  }

  return { init, refresh, setFolder, restore, selectMemo, setParam, anchor, drag, audition, pull, pullResult, setTempo, setSetPath, setTarget };
}

module.exports = { createController };
```

```js
    return JSON.parse(fs.readFileSync(SETTINGS, 'utf8'));
  } catch {
    return {};

  fs.mkdirSync(CACHE_DIR, { recursive: true });
  fs.writeFileSync(SETTINGS, JSON.stringify({ ...loadSettings(), ...patch }, null, 2));

let queue = Promise.resolve();
function send(type, ...args) {
  const isDict = args.length === 1 && args[0] !== null && typeof args[0] === 'object';
  queue = queue
    .then(async () => {
      if (isDict) {
        const name = `${PREFIX}_${type}`;
        await maxApi.setDict(name, args[0]);
        await maxApi.outlet(type, name);
      } else {
        await maxApi.outlet(type, ...args);
      }
    })
    .catch((e) => maxApi.post(`vm-core send ${type} failed: ${e.message}`));
  return queue;
}
```

```js
// lom-bridge.js — Live Object Model bridge for VoiceMemo. Max [js], ES5.
autowatch = 1;
inlets = 1;
outlets = 1;

var trackPath = null;
var trackNumber = 0;
var hasFilePath = false;
var ready = false;
var last = {};

function stripQuotes(s) {
  return String(s).replace(/^"|"$/g, '');
}

function init() {
  var dev = new LiveAPI('this_device');
  var m = /^(live_set tracks (\d+))/.exec(stripQuotes(dev.path));
  trackPath = m ? m[1] : null;
  trackNumber = m ? Number(m[2]) + 1 : 0;
  var song = new LiveAPI('live_set');
  hasFilePath = String(song.info).indexOf('property file_path') >= 0;
  ready = true;
  last = {};
  refresh();
}

function emit(key) {
  var args = Array.prototype.slice.call(arguments, 1);
  var sig = args.join(' ');
  if (last[key] === sig) return;
  last[key] = sig;
  outlet(0, [key].concat(args));
}

function findSlot() {
  if (!trackPath) return { ok: 0, label: 'Place on an audio track' };
  var track = new LiveAPI(trackPath);
  if (Number(track.get('has_midi_input')) === 1) return { ok: 0, label: 'Place on an audio track' };
  var start = 0;
  var hl = new LiveAPI('live_set view highlighted_clip_slot');
  var hm = / clip_slots (\d+)$/.exec(stripQuotes(hl.path));
  if (hm) start = Number(hm[1]);
  var count = track.getcount('clip_slots');
  for (var i = start; i < count; i++) {
    var slot = new LiveAPI(trackPath + ' clip_slots ' + i);
    if (Number(slot.get('has_clip')) === 0) {
      return { ok: 1, index: i, label: 'T' + trackNumber + ' · Slot ' + (i + 1) };
    }
  }
  return { ok: 0, label: 'No empty slot below selection' };
}

function refresh() {
  if (!ready) return;
  var song = new LiveAPI('live_set');
  emit('tempo', Number(song.get('tempo')), Number(song.get('signature_numerator')));
  if (hasFilePath) emit('setpath', stripQuotes([].concat(song.get('file_path')).join(' ')));
  var t = findSlot();
  emit('target', t.ok, t.label);
}

function bang() {
  refresh();
}

function resend() {
  last = {};
  refresh();
}

function pull() {
  var p = Array.prototype.slice.call(arguments).join(' ');
  var t = findSlot();
  if (!t.ok) {
    outlet(0, ['pullresult', 0, t.label]);
    return;
  }
  var slot = new LiveAPI(trackPath + ' clip_slots ' + t.index);
  slot.call('create_audio_clip', p);
  if (Number(slot.get('has_clip')) === 1) {
    outlet(0, ['pullresult', 1, 'Pulled to ' + t.label]);
    resend();
  } else {
    outlet(0, ['pullresult', 0, 'Clip not created (needs Live 12.0.5+)']);
  }
}
```

```js
// theme.js — Live theme colours for VoiceMemo jsui scripts. ES5.
// max.getcolor() reads Live's dynamic colours (Max 8.2+); fallbacks match Live's dark theme.
var THEME = {};
function themeColor(name, fallback) {
  try {
    var c = max.getcolor(name);
    if (c && c.length >= 3) return [c[0], c[1], c[2], c.length > 3 ? c[3] : 1];
  } catch (e) {}
  return fallback;
}
function loadTheme() {
  THEME.bg = themeColor('live_lcd_bg', [0.09, 0.09, 0.1, 1]);
  THEME.frame = themeColor('live_lcd_frame', [0.22, 0.22, 0.24, 1]);
  THEME.fg = themeColor('live_lcd_control_fg', [0.86, 0.86, 0.86, 1]);
  THEME.dim = themeColor('live_lcd_passive', [0.48, 0.48, 0.5, 1]);
  THEME.accent = themeColor('live_lcd_control_fg_alt', [1.0, 0.66, 0.2, 1]);
  THEME.title = themeColor('live_lcd_title', [0.95, 0.95, 0.95, 1]);
}
function withAlpha(c, a) {
  return [c[0], c[1], c[2], a];
}
function setColor(c) {
  mgraphics.set_source_rgba(c[0], c[1], c[2], c[3]);
}
function text(str, x, y, size, color, bold) {
  mgraphics.select_font_face('Arial', 'normal', bold ? 'bold' : 'normal');
  mgraphics.set_font_size(size);
  setColor(color);
  mgraphics.move_to(x, y);
  mgraphics.show_text(String(str));
}
function textWidth(str, size, bold) {
  mgraphics.select_font_face('Arial', 'normal', bold ? 'bold' : 'normal');
  mgraphics.set_font_size(size);
  return mgraphics.text_measure(String(str))[0];
}
function readDict(name) {
  var d = new Dict(name);
  return JSON.parse(d.stringify());
}
function fmtTime(s, decimals) {
  if (s === null || s === undefined || isNaN(s)) return '';
  var neg = s < 0;
  s = Math.abs(s);
  var h = Math.floor(s / 3600);
  var m = Math.floor((s % 3600) / 60);
  var sec = s % 60;
  var secStr = decimals ? sec.toFixed(decimals) : String(Math.floor(sec));
  if (Number(secStr) < 10) secStr = '0' + secStr;
  var out = (h ? h + ':' + (m < 10 ? '0' : '') + m : m) + ':' + secStr;
  return (neg ? '-' : '') + out;
}
var MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
function fmtDate(iso) {
  if (!iso) return '';
  var d = new Date(iso);
  if (isNaN(d.getTime())) return '';
  return d.getDate() + ' ' + MONTHS[d.getMonth()];
}
```

```js
// memo-list.js — scrollable two-line memo list. Max [jsui], ES5.
include('theme.js');
mgraphics.init();
mgraphics.relative_coords = 0;
mgraphics.autofill = 0;
inlets = 1;
outlets = 1;

var ROW = 28;
var items = [];
var visible = [];
var filterText = '';
var selectedId = null;
var scroll = 0;
var dragStartY = null;
var dragScroll = 0;
var dragged = false;
loadTheme();

function size() {
  return [box.rect[2] - box.rect[0], box.rect[3] - box.rect[1]];
}
function clampScroll() {
  var h = size()[1];
  var max = Math.max(0, visible.length * ROW - h);
  scroll = Math.max(0, Math.min(max, scroll));
}
function theme() {
  loadTheme();
  mgraphics.redraw();
}
function memos(name) {
  items = readDict(name).items || [];
  applyFilter();
}
function filter() {
  filterText = Array.prototype.slice.call(arguments).join(' ').toLowerCase();
  applyFilter();
}
function applyFilter() {
  visible = [];
  for (var i = 0; i < items.length; i++) {
    if (!filterText || String(items[i].title).toLowerCase().indexOf(filterText) >= 0) visible.push(items[i]);
  }
  clampScroll();
  mgraphics.redraw();
}
function select() {
  selectedId = Array.prototype.slice.call(arguments).join(' ');
  for (var i = 0; i < visible.length; i++) {
    if (visible[i].id === selectedId) scroll = i * ROW - ROW;
  }
  clampScroll();
  mgraphics.redraw();
}

function paint() {
  var s = size();
  var w = s[0];
  var h = s[1];
  setColor(THEME.bg);
  mgraphics.rectangle(0, 0, w, h);
  mgraphics.fill();
  if (!visible.length) {
    text(items.length ? 'No matches' : 'No memos', 8, 18, 10, THEME.dim, false);
    return;
  }
  for (var i = 0; i < visible.length; i++) {
    var y = i * ROW - scroll;
    if (y + ROW < 0 || y > h) continue;
    var m = visible[i];
    var sel = m.id === selectedId;
    var cloud = m.status !== 'local';
    if (sel) {
      setColor(withAlpha(THEME.accent, 0.18));
      mgraphics.rectangle(0, y, w, ROW - 1);
      mgraphics.fill();
      setColor(THEME.accent);
      mgraphics.rectangle(0, y, 2, ROW - 1);
      mgraphics.fill();
    }
    var main = cloud ? THEME.dim : sel ? THEME.title : THEME.fg;
    var dur = fmtTime(m.duration, 0);
    var durW = textWidth(dur, 10, false);
    var title = String(m.title);
    while (title.length > 1 && textWidth(title, 10, sel) > w - durW - 18) title = title.slice(0, -2) + '…';
    text(title, 7, y + 12, 10, main, sel);
    text(dur, w - durW - 6, y + 12, 10, THEME.dim, false);
    text(fmtDate(m.date) + (cloud ? '  ☁ in iCloud' : ''), 7, y + 24, 9, THEME.dim, false);
  }
  if (visible.length * ROW > h) {
    var barH = Math.max(12, (h * h) / (visible.length * ROW));
    var barY = (scroll / (visible.length * ROW - h)) * (h - barH);
    setColor(withAlpha(THEME.fg, 0.25));
    mgraphics.rectangle(w - 3, barY, 2, barH);
    mgraphics.fill();
  }
}

function onclick(x, y) {
  dragStartY = y;
  dragScroll = scroll;
  dragged = false;
}
function ondrag(x, y, button) {
  if (dragStartY === null) return;
  if (Math.abs(y - dragStartY) > 3) dragged = true;
  if (dragged) {
    scroll = dragScroll - (y - dragStartY);
    clampScroll();
    mgraphics.redraw();
  }
  if (!button) {
    if (!dragged) {
      var i = Math.floor((dragStartY + scroll) / ROW);
      if (i >= 0 && i < visible.length) {
        selectedId = visible[i].id;
        mgraphics.redraw();
        outlet(0, 'select', selectedId);
      }
    }
    dragStartY = null;
  }
}
function onwheel(x, y, dx, dy) {
  scroll -= dy * 40;
  clampScroll();
  mgraphics.redraw();
}
```

```js
// wave-view.js — waveform, segment chips, window bracket and state overlays. Max [jsui], ES5.
include('theme.js');
mgraphics.init();
mgraphics.relative_coords = 0;
mgraphics.autofill = 0;
inlets = 1;
outlets = 1;

var HEADER_H = 14;
var CHIP_H = 11;
var RULER_H = 10;
var head = null;
var peaks = [];
var duration = 0;
var segs = [];
var win = null;
var prog = null;
var st = { name: 'idle' };
var buttons = [];
var dragEdge = null;
loadTheme();

function size() {
  return [box.rect[2] - box.rect[0], box.rect[3] - box.rect[1]];
}
function waveRect() {
  var s = size();
  return { x: 0, y: HEADER_H + 2, w: s[0], h: s[1] - HEADER_H - CHIP_H - RULER_H - 6 };
}
function chipY() {
  var r = waveRect();
  return r.y + r.h + 2;
}
function tToX(t) {
  return duration > 0 ? (t / duration) * size()[0] : 0;
}
function xToT(x) {
  return Math.max(0, Math.min(duration, (x / size()[0]) * duration));
}

function theme() { loadTheme(); mgraphics.redraw(); }
function header(name) { head = readDict(name); mgraphics.redraw(); }
function waveform(name) {
  var d = readDict(name);
  peaks = d.peaks || [];
  duration = d.duration || 0;
  prog = null;
  mgraphics.redraw();
}
function segments(name) { segs = readDict(name).items || []; mgraphics.redraw(); }
function window(name) { win = readDict(name); mgraphics.redraw(); }
function progress(name) { prog = readDict(name); mgraphics.redraw(); }
function state(name) {
  st = readDict(name);
  if (st.name === 'loading') { peaks = []; segs = []; win = null; }
  mgraphics.redraw();
}

function drawButton(label, x, y, id) {
  var w = textWidth(label, 10, true) + 16;
  setColor(withAlpha(THEME.accent, 0.9));
  mgraphics.rectangle_rounded(x, y, w, 18, 4, 4);
  mgraphics.fill();
  text(label, x + 8, y + 13, 10, THEME.bg, true);
  buttons.push({ id: id, x: x, y: y, w: w, h: 18 });
  return w;
}

function paintOverlay(w, h) {
  if (st.name === 'no-access') {
    text('Voice Memos is locked by macOS privacy settings.', 12, 36, 11, THEME.title, true);
    text('Give Ableton Live Full Disk Access, then restart Live.', 12, 52, 10, THEME.fg, false);
    var bw = drawButton('Open Settings', 12, 64, 'opensettings');
    text('or', 12 + bw + 8, 77, 10, THEME.dim, false);
    drawButton('Use a folder…', 12 + bw + 26, 64, 'choosefolder');
    return true;
  }
  if (st.name === 'empty') {
    text('No voice memos found.', 12, 36, 11, THEME.title, true);
    text('Turn on iCloud sync for Voice Memos, or point the device at a folder.', 12, 52, 10, THEME.fg, false);
    drawButton('Use a folder…', 12, 64, 'choosefolder');
    return true;
  }
  if (st.name === 'idle') {
    text('← Pick a memo', 12, h / 2, 11, THEME.dim, false);
    return true;
  }
  if (st.name === 'error' || st.name === 'notice') {
    text(st.name === 'error' ? 'Could not load this memo' : 'Not available', 12, 40, 11, THEME.title, true);
    text(st.message || '', 12, 56, 10, THEME.fg, false);
    return true;
  }
  return false;
}

function paint() {
  var s = size();
  var w = s[0];
  var h = s[1];
  buttons = [];
  setColor(THEME.bg);
  mgraphics.rectangle(0, 0, w, h);
  mgraphics.fill();
  if (head) {
    var line = '“' + head.title + '”  ·  ' + fmtTime(head.duration, 0) + '  ·  ' + fmtDate(head.date);
    text(line, 4, 11, 10, THEME.title, true);
  }
  if (paintOverlay(w, h)) return;

  var r = waveRect();
  var mid = r.y + r.h / 2;
  var bins = peaks.length / 2;
  if (win) {
    setColor(withAlpha(THEME.accent, 0.14));
    mgraphics.rectangle(tToX(win.start), r.y, Math.max(1, tToX(win.end) - tToX(win.start)), r.h + CHIP_H + 2);
    mgraphics.fill();
  }
  for (var b = 0; b < bins; b++) {
    var x = (b / bins) * w;
    var t = (b / bins) * duration;
    var inWin = win && t >= win.start && t <= win.end;
    setColor(inWin ? THEME.accent : THEME.fg);
    var lo = peaks[2 * b];
    var hi = peaks[2 * b + 1];
    mgraphics.rectangle(x, mid - hi * (r.h / 2), Math.max(1, w / bins - 0.3), Math.max(1, (hi - lo) * (r.h / 2)));
    mgraphics.fill();
  }
  var cy = chipY();
  for (var i = 0; i < segs.length; i++) {
    var x0 = tToX(segs[i].start);
    var x1 = Math.max(x0 + 3, tToX(segs[i].end));
    setColor(withAlpha(THEME.fg, 0.22));
    mgraphics.rectangle_rounded(x0, cy, x1 - x0, CHIP_H, 3, 3);
    mgraphics.fill();
    if (x1 - x0 > 12) text(String(i + 1), x0 + 3, cy + 9, 9, THEME.fg, true);
  }
  if (win) {
    setColor(THEME.accent);
    mgraphics.rectangle(tToX(win.start) - 1, r.y, 2, r.h + CHIP_H + 2);
    mgraphics.fill();
    mgraphics.rectangle(tToX(win.end) - 1, r.y, 2, r.h + CHIP_H + 2);
    mgraphics.fill();
  }
  var ry = h - 2;
  var steps = 4;
  for (var k = 0; k <= steps; k++) {
    var tt = (duration * k) / steps;
    var label = fmtTime(tt, 0);
    var lx = Math.min(w - textWidth(label, 9, false) - 2, Math.max(2, tToX(tt) - textWidth(label, 9, false) / 2));
    text(label, lx, ry, 9, THEME.dim, false);
  }
  if (st.name === 'loading' || (prog && prog.fraction < 1)) {
    var f = prog ? prog.fraction : 0;
    setColor(withAlpha(THEME.accent, 0.8));
    mgraphics.rectangle(0, r.y + r.h - 2, w * f, 2);
    mgraphics.fill();
    text(prog && prog.phase === 'full' ? 'Preparing full quality…' : 'Converting…', 4, r.y + 12, 9, THEME.dim, false);
  }
}

function hitButton(x, y) {
  for (var i = 0; i < buttons.length; i++) {
    var b = buttons[i];
    if (x >= b.x && x <= b.x + b.w && y >= b.y && y <= b.y + b.h) return b.id;
  }
  return null;
}

function onclick(x, y) {
  var id = hitButton(x, y);
  if (id) { outlet(0, id); return; }
  if (st.name !== 'ready' || duration <= 0) return;
  if (win && Math.abs(x - tToX(win.start)) < 5) { dragEdge = 'start'; return; }
  if (win && Math.abs(x - tToX(win.end)) < 5) { dragEdge = 'end'; return; }
  var cy = chipY();
  if (y >= cy && y <= cy + CHIP_H) {
    var t = xToT(x);
    for (var i = 0; i < segs.length; i++) {
      if (t >= segs[i].start && t <= segs[i].end) { outlet(0, 'segment', i); return; }
    }
  }
  outlet(0, 'anchor', xToT(x));
}

function ondrag(x, y, button) {
  if (!dragEdge || !win) return;
  var t = xToT(x);
  if (dragEdge === 'start') win.start = t;
  else win.end = t;
  mgraphics.redraw();
  if (!button) {
    outlet(0, 'drag', win.start, win.end);
    dragEdge = null;
  }
}
```

```markdown
# VoiceMemo for Ableton Live

A Max for Live audio effect that browses your iCloud-synced Apple Voice Memos, shows a waveform with auto-detected segments and rough analysis (level, tempo≈, key≈, speech/music), and pulls a chosen window into a Session clip slot.

## Requirements
- Ableton Live 12.0.5+ Suite (or Standard + Max for Live), macOS 13+
- Voice Memos syncing via iCloud on this Mac
- **Full Disk Access for Ableton Live** (System Settings → Privacy & Security → Full Disk Access), then restart Live. Without it the device can still read a folder you choose.

## Use
1. Drop `device/VoiceMemo.amxd` on an audio track.
2. Pick a memo on the left.
3. Pick a window: click a numbered segment, or choose a length (bars follow Set tempo) and click the waveform. Drag the bracket edges to fine-tune; ▶ to audition.
4. Select a clip slot on the track and press **PULL**.

Pulled WAVs go to `<Set folder>/Samples/Imported/VoiceMemo/` (or `~/Music/Ableton/User Library/VoiceMemo Cache/Pulled/` for unsaved Sets). The device never modifies your Voice Memos library.

## Development
- `npm test`: unit tests (Node 22+).
- `npm run build`: regenerate `device/VoiceMemo.amxd` (dev build references `src/` by absolute path).
- Design: `docs/superpowers/specs/2026-10-12-voicememo-m4l-design.md`; manual checks: `docs/testing-checklist.md`.
```
